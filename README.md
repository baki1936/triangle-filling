# Triangle Filling and Shading Algorithms

Implementation of several computer graphics shading techniques in Python.

## Implemented Algorithms

- Flat Shading
- Gouraud Shading
- Texture Mapping
- Vector Interpolation

## Project Structure

- `flat_shading.py` - Flat shading implementation
- `gouraud_shading.py` - Gouraud shading implementation
- `texture_maps_shading.py` - Texture mapping implementation
- `render_img.py` - Rendering image function
- `vector_interp.py` - Vector interpolation function
